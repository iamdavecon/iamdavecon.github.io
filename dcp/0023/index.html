Sticker Inventory Reconciliation

1. Abstract

This document defines a lightweight accounting procedure for determining whether sticker supply is adequate, fictional, or already in someone else’s pocket.

2. Inventory States

Inventory MAY be classified as AVAILABLE, RESERVED, IN_TRANSIT, ATTACHED, or VAGUELY REMEMBERED.

3. Counting

  1. Count visible stickers.
  2. Exclude stickers currently attached to property unless removal has been approved.
  3. Do not count a sticker promised by a Dave who is not currently locatable.
  4. Record an approximate total if exact counting would prevent sticker exchange.

4. Scarcity

Scarcity SHOULD NOT be used to pressure a recipient into accepting an unwanted sticker. A low inventory is an operational condition, not a moral emergency.
