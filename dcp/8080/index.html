Dave over HTTP

1. Abstract

This document proposes a transport-layer protocol for delivering Dave over ordinary networks. The reference implementation has not been located.

2. Request Model

GET /dave HTTP/1.1
Host: davecon.local
Accept: text/dave

A successful response SHOULD contain a Dave, a Dave-adjacent entity, or a useful explanation of why neither was available.

3. Status Codes

200 DAVE_OK indicates a Dave was returned. 404 DAVE_NOT_FOUND indicates that discovery failed. 418 DAVE_IS_A_TEAPOT is retained for compatibility and should not be interpreted literally.

4. Caching

Dave responses MUST NOT be cached indefinitely. A cached Dave may have moved, ascended, acquired a hot dog, or become unavailable due to social battery.

5. Security Considerations

Transport encryption is RECOMMENDED. Authentication does not establish Dave status; see DCP-0001.
