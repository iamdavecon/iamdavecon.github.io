Dave Name Collision Resolution

1. Abstract

This document defines fallback identifiers for environments containing more Daves than available first names.

2. Collision Detection

A collision exists when two or more Daves respond to the same name, or when a non-Dave named Dave responds before the relevant Dave does.

3. Resolution

  1. Ask each endpoint which identifier it prefers.
  2. Preserve self-identification where practical.
  3. Use role, location, artifact, or tasteful alias as a secondary discriminator.
  4. Do not assign “real Dave” to one endpoint unless the situation is explicitly ceremonial.

4. David Compatibility

David MAY be treated as an expanded Dave, a separate identifier, or an implementation detail. The choice MUST be documented if it affects food distribution.

5. Security Considerations

Identifiers MUST NOT reveal private information or be used to ridicule an endpoint. Name resolution should resolve the name, not the person.
