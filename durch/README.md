# DURCH — The Dave Church

This folder contains the static, single-page Durch site for DaveCon.

## Structure

- `index.html` — semantic page content and all Durch doctrine
- `style.css` — responsive monochrome/zine visual system and print styles
- `durch.js` — Ask the Dave, initiation certificates, local state, and Easter eggs

No build step, framework, external dependency, tracking, or backend is required. Open `index.html` directly or serve the repository root with any static file server.

Initiation records are stored only in the visitor's browser with `localStorage`. Certificate printing uses the browser print dialog.
